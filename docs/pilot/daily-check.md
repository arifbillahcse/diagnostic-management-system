## Where to find the DMS numbers

- Totals, payments and dues: the **Day close** / collection report for the day
- Reports pending: Laboratory work list, filter "not delivered"

## When something does not match

1. Find the order where the difference is.
2. Decide: wrong in the old way, wrong in DMS, or entered differently.
3. If DMS is wrong, write it in [issue-log.csv](issue-log.csv) with the order number.
4. Do not edit or delete in DMS to make it match. Use a refund or an
   adjustment, which keeps the record.
