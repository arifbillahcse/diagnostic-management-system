# Reception — quick guide

## New patient, new order

1. **Front desk → New order.**
2. Search the patient by mobile number. Not found? **Add patient** (name,
   age, sex, mobile).
3. Choose the referring doctor (or none).
4. Add the tests. Check the price shown.
5. Discount only if allowed for you, with the reason.
6. Take the payment: amount, method (cash, card, bKash/Nagad).
7. **Save** and **Print receipt**. Give the receipt to the patient.

## Patient pays the due later

Open the order (search by order number or mobile) → **Take payment** →
print the receipt.

## Patient collects the report

Open the order → check the status shows the report is ready → print or hand
over. If there is a due, it must be paid first unless the owner allows it.

## Mistakes

- Wrong test added: **cancel** that test before the sample is taken; a
  refund is made if it was paid.
- Wrong amount taken: do a **refund** or take the extra payment. Never ask
  for a record to be deleted.
- Wrong patient details: edit the patient; the order keeps its history.

## Rules

- Sign in with your own account. Never use someone else's.
- Sign out (or lock the screen) when you leave the counter.
- Something looks wrong? Tell the owner and write down the order number.
