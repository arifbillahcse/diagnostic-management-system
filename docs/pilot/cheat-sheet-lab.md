# Laboratory — quick guide

## Samples

1. **Laboratory → Samples.** Scan or type the sample barcode.
2. **Collect** when the sample is taken; **Receive** when it reaches the lab.
3. Bad sample (clotted, too little, wrong tube): **Reject** with the reason.
   Reception sees it and calls the patient.

## Results

1. **Laboratory → Work list.** Open the test.
2. Enter the values. Values outside the range are marked; check them twice.
3. **Save.** A second person **verifies** if your clinic uses verification.
4. Verified results go to the report and can be printed.

## Corrections

A verified result is never overwritten. Open it → **Correct** → enter the
new value and the reason. The report shows the new version; the old one
stays in the history.

## Analyzer results

Results from a connected analyzer arrive on the work list. Check them before
verifying. If a result does not arrive, enter it by hand and tell the owner.

## Rules

- Your own account only.
- Never verify your own result if the clinic requires a second person.
- Unsure of a value? Do not release it. Ask the pathologist.
